GitHub Commands Cheat Sheet

1. Repository Commands

Task Command
Clone Repo git clone repository_url
Initialize Git git init
Check Status git status
View Remote git remote -v

2. Branch Commands

Task Command
Create Branch git branch branch_name
Switch Branch git checkout branch_name
Create + Switch git checkout -b branch_name
List Branches git branch
Delete Branch git branch -d branch_name

3. Add, Commit & Push

Task Command
Add Single File git add file_name
Add All Files git add .
Commit Changes (message is necessary) git commit -m "message"
Push Code git push origin branch_name
Pull Latest Code git pull origin branch_name

4. Merge And Rebase

Task Command
Merge Branch git merge branch_name
Rebase Branch git rebase branch_name
Abort Rebase git rebase --abort
Continue Rebase git rebase --continue

5. Stash Commands

Task Command
Save Stash git stash
View Stash git stash list
Apply Stash git stash apply
Delete Stash git stash drop

6. Undo Commands

Task Command
Reset Commit git reset --soft HEAD~1
Hard Reset git reset --hard HEAD~1
Revert Commit git revert commit_id
Amend Commit git commit --amend

7. Advanced Commands

Task Command
Cherry Pick git cherry-pick commit_id
Force Push git push --force
View Logs git log
Short Logs git log --oneline
